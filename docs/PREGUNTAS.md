# ❓ Preguntas Guía para Mejorar el Proyecto

> Este archivo no es una lista de tareas: es para **pensar**.
> Responde por escrito debajo de cada pregunta (`**R:**`). Con el tiempo, tus respuestas se vuelven decisiones de diseño.
> Puedes pegar una sección completa a una IA y pedirle que te **entreviste** o que cuestione tus respuestas.

- [ ] ¿Cómo evitar la fricción de tener que llenar todos los campos?
- [ ] ¿Qué elementos de gamificación debería implementar para mantener a la audiencia atrapada?
- [ ] ¿Cómo podría automatizar el proceso de ingesta de datos? ¿"monitoreando" la actividad del usuario para rellenar?
- [ ] ¿Cómo me enfrento a la deuda técnica de hacer todo con agentes de IA y LLMs?
